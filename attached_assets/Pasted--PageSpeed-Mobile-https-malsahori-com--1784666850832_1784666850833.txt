نفّذ جولة نهائية مركزة لتحسين PageSpeed Mobile للموقع:
https://malsahori.com

الوضع الحالي الظاهر في Lighthouse:

- Speed Index يقارب 5.2s

- TBT يقارب 80ms

- CLS = 0

- Render-blocking resources تؤخر العرض قرابة 1060ms

- Unused JavaScript يقارب 218KB

- Cache savings تقارب 733KB

- Image savings بقيت قرابة 58KB فقط

الصور ليست المشكلة الأساسية الآن.

المطلوب إصلاح الموارد التي تمنع الرسم وتقليل JavaScript الأولي، دون تغيير التصميم أو الوظائف.

==================================================

1. تحليل الموارد التي تمنع الرسم

==================================================

افتح كل بند داخل:

طلبات حظر العرض / Render-blocking resources

وحدد بدقة:

- اسم كل ملف

- حجمه

- زمن تأخيره

- هل هو CSS أو font أو JavaScript

- هل هو محلي أو تابع لطرف ثالث

أنشئ جدولًا في التقرير قبل التنفيذ.

==================================================

2. Critical CSS

==================================================

استخرج فقط CSS المطلوب لعرض:

- Header

- Hero

- النص الرئيسي

- الأزرار الظاهرة أولًا

- تخطيط الهاتف فوق Fold

ضع Critical CSS داخل HTML الأولي أو اجعله في ملف صغير جدًا يُحمّل أولًا.

حمّل بقية CSS بعد أول رسم بطريقة لا تمنع العرض.

لا تكرر CSS نفسه مرتين.

لا تغيّر التصميم.

==================================================

3. إزالة CSS غير المستخدم

==================================================

شغّل تحليلًا فعليًا للـ CSS المستخدم في الصفحة الرئيسية.

احذف أو قسّم:

- أنماط لوحة الإدارة

- أنماط صفحات الامتحانات

- أنماط Study Room

- أنماط PDF Viewer

- أنماط الجداول والرسوم

- أنماط الصفحات غير الموجودة في الصفحة الرئيسية

لا تجعل ملف CSS الرئيسي يحتوي على أنماط المنصة كاملة.

استخدم page-level CSS splitting.

==================================================

4. تحسين الخطوط

==================================================

راجع كل الخطوط والأوزان.

المطلوب:

- WOFF2 فقط

- font-display: swap

- عدم استخدام CSS @import لجلب الخطوط

- تحميل 400 و600 و700 فقط عند الحاجة

- preload لخط واحد فقط مستخدم في Hero

- عدم preload لبقية الأوزان

- Cache-Control طويل للخطوط

- fallback عربي مناسب يظهر فورًا

تحقق أن عنوان Hero لا ينتظر تحميل الخط.

==================================================

5. تقليل JavaScript غير المستخدم

==================================================

يوجد قرابة 218KB JavaScript غير مستخدم.

أنشئ bundle analyzer وحدد أكبر الوحدات.

تأكد أن الصفحة الرئيسية لا تحمّل:

- لوحة الإدارة

- محرر الامتحانات

- PDF viewer

- chart libraries

- rich text editor

- date libraries كاملة

- Study Room

- Study Schedule

- مكتبات رفع الملفات

- مكتبات الجداول

- أي مكوّن لا يظهر على الصفحة الرئيسية

طبّق React.lazy وdynamic import على جميع هذه الأجزاء.

==================================================

6. تقسيم الصفحة الرئيسية نفسها

==================================================

حمّل مباشرة فقط:

- Header

- Hero

- أول قسم ظاهر

أما الأقسام الموجودة أسفل الشاشة فاجعلها:

- lazy loaded

- أو dynamic imported

- أو تبدأ بعد requestIdleCallback

- أو عند الاقتراب منها باستخدام IntersectionObserver

لا تجعل Hero ينتظر هذه الأقسام.

==================================================

7. الطرف الثالث

==================================================

راجع:

- Analytics

- Clarity

- tracking

- chat tools

- external fonts

- social widgets

لا تحملها قبل LCP.

حمّلها بعد:

- window.load

- أو أول تفاعل

- أو requestIdleCallback

إن لم تكن ضرورية، احذفها.

==================================================

8. التخزين المؤقت المتبقي

==================================================

يوجد توفير قرابة 733KB.

تحقق من رؤوس الاستجابة في الإنتاج.

للملفات ذات hash:

Cache-Control: public, max-age=31536000, immutable

يشمل:

- JS

- CSS

- WOFF2

- AVIF

- WebP

- SVG

للـ HTML:

Cache-Control: no-cache

استخدم versioned URLs للصور الديناميكية حتى يمكن تخزينها طويلًا.

==================================================

9. طلبات الشبكة الحرجة

==================================================

اختصر المسار ليصبح:

HTML

→ Critical CSS

→ LCP image

لا تسمح بمسار مثل:

HTML

→ large CSS

→ font stylesheet

→ font

→ JS

→ API

→ Hero

افحص Network Dependency Tree بعد التعديل.

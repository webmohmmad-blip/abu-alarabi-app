==================================================

WEEKLY QUIZ PUBLISHING RULES

==================================================

A weekly quiz should appear to students only when:

- type = WEEKLY_QUIZ

- status = PUBLISHED

- publishAt is null or publishAt <= current time

- closeAt is null or closeAt > current time

- archivedAt is null

- deletedAt is null

- the student matches the target group, grade, or track

- the quiz contains at least one valid question if this is required

Audit whether the admin form saves the quiz as:

DRAFT

instead of:

PUBLISHED

If the user clicks Publish, ensure the backend actually updates the status.

3. Student confirms starting

4. Call:

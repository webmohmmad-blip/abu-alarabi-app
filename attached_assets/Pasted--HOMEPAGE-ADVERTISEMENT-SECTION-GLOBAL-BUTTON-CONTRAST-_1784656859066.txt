# HOMEPAGE ADVERTISEMENT SECTION + GLOBAL BUTTON CONTRAST FIX
# Abu Al-Arabi Platform
You are a senior full-stack engineer and UI/UX specialist.
Implement a complete advertisement management system for the large homepage area shown below the main navigation and above the rest of the homepage content.
The advertisement area must be fully manageable from the Admin Dashboard.
Do not only create a static banner.
Build a complete production-ready advertisement system with backend, database, admin management, frontend rendering, responsive design, validation, and testing.
==================================================
PART 1: ADVERTISEMENT SYSTEM GOAL
==================================================
Create a homepage advertisement section where the admin can:
- add an advertisement
- upload an advertisement image
- enter a title
- enter an optional description
- add an optional destination link
- choose whether the link opens:
 - in the same tab
 - in a new tab
- activate or deactivate the advertisement
- schedule when it starts
- schedule when it ends
- reorder advertisements
- edit advertisements
- delete advertisements
- preview advertisements
- hide the entire advertisement section if there are no active advertisements
The student must never see draft, disabled, expired, or scheduled-future advertisements.

PART 11: GLOBAL BUTTON CONTRAST ISSUE
==================================================
There is a UI bug across the website where some buttons have:
- white background
- white text
This makes the button text invisible.
Audit every button in the entire platform.
Search for:
- white text on white background
- transparent backgrounds with white text on light sections
- hover states that remove contrast
- disabled states with unreadable labels
- ghost buttons with poor visibility
- outline buttons with missing border contrast
Fix the design system globally.
Do not patch individual buttons randomly if they use shared button components.
Inspect:
- shared Button component
- CSS variables
- Tailwind variants
- theme tokens
- dark mode
- light mode
- hover states
- focus states
- disabled states
==================================================
PART 12: APPROVED BUTTON STYLES
==================================================
Use consistent variants.
Primary button:
- background: #5A2D82
- text: white
- hover: darker purple
- focus ring visible
Secondary button:
- background: #0D9BB5
- text: white
Gold/accent button:
- background: #C79A2D
- text: dark readable color or white only if contrast passes
White button on dark background:
- background: white
- text: #5A2D82 or #1F2937
- visible border if needed
Outline button:
- transparent background
- border: #5A2D82
- text: #5A2D82
- hover background: light purple
- hover text: dark purple
Ghost button:
- transparent background
- readable text depending on background
- visible hover state
Disabled:
- reduced opacity
- still readable
- cursor not-allowed
Never allow:
background: white
color: white
unless an image or strong dark overlay guarantees readability, and even then avoid it.

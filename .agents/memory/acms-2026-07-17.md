## What was built

### Database schema additions (lib/db/src/schema/)
- `contentStatusEnum` (draft | published | archived | hidden | scheduled) — added to content.ts
- `status`, `publishedAt`, `scheduledAt`, `expiresAt` added to `dossiersTable` and `worksheetsTable`
- `status`, `questionCount`, `publishedAt`, `scheduledAt`, `expiresAt` added to `examsTable`
- New `summariesTable` (content.ts): title, description, subjectId, grade, type (text/pdf/print), content, fileUrl, status, views
- New `summaryTypeEnum` (text | pdf | print)
- DB migration run via `pnpm --filter @workspace/db run push` — all columns created

### New API routes (artifacts/api-server/src/routes/)
- `admin-questions.ts` — mounted at `/admin`:
  - `GET /admin/exams/:examId/questions` — list questions with choices
  - `POST /admin/exams/:examId/questions` — create question with choices (all 7 types)
  - `PATCH /admin/questions/:id` — update question + replace choices
  - `DELETE /admin/questions/:id` — delete question, refreshes exam totalScore
  - `POST /admin/exams/:examId/questions/reorder` — reorder questions
  - `POST /admin/exams/:id/duplicate` — full exam + question + choice duplication
  - Auto-refreshes `totalScore` and `questionCount` on examsTable after any question change
- `admin-summaries.ts` — mounted at `/admin`:
  - `GET /admin/summaries`, `POST /admin/summaries`, `PATCH /admin/summaries/:id`, `DELETE /admin/summaries/:id`
- `summaries.ts` — public/student:
  - `GET /summaries` (published only, filter by subjectId), `GET /summaries/:id` (increments views)
- Updated `admin.ts`:
  - Added `GET /admin/exams` — list all exams for admin (includes status, questionCount)
  - Updated `POST /admin/exams` — properly handles status, questionCount, isAvailable

### New frontend pages (artifacts/abu-alarabi/src/pages/)
- `admin/exams.tsx` — full exam builder:
  - Stats bar (total/published/draft/archived)
  - Search + status filter tabs
  - Per-exam actions: publish, unpublish, archive, duplicate, edit, delete
  - Inline "Manage Questions" expandable panel
  - Question builder supports all 7 types: MCQ (A/B/C/D choices), true_false, fill_blank, matching, ordering, essay
  - Exam metadata modal: title, subject, type, duration, max attempts, passing score, instructions, status
- `admin/summaries.tsx` — summaries management:
  - Stats, search, status filters
  - Add/edit modal: title, subject, grade, type, content (text or PDF URL), status
  - Per-row: publish/unpublish, archive, edit, delete
- `summaries.tsx` — student summaries library:
  - Subject filter pills + type filter (all/text/pdf/print)
  - Card grid with subject color accent borders
  - SummaryModal: inline text reader for "text" type, iframe for PDF, new tab for print

### Routing updates
- `App.tsx`: added `/summaries` (student), `/admin/exams`, `/admin/summaries`
- `admin-layout.tsx`: added "الامتحانات" + "الملخصات" to admin nav
- `sidebar.tsx`: added "الملخصات" link with BookText icon

## Key design decisions
- Questions auto-recalculate exam `totalScore` and `questionCount` on every add/update/delete
- Content status enum is shared across dossiers, worksheets, exams, summaries
- Exam duplication copies all questions AND choices recursively
- Student summaries page: type "print" → opens PDF in new tab instead of iframe modal
